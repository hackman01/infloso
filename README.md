# Project Documentation

This repository contains two main projects: MelodyVerse (music streaming platform) and ConnectVerse (social media platform).

## MelodyVerse 🎵

MelodyVerse is a modern music streaming platform built with React.js, Framer Motion, and Tailwind CSS.

### Setup Instructions

1. Navigate to the MelodyVerse directory:
```bash
cd melodyverse
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit:
```
http://localhost:3000
```

### Tech Stack
- React.js
- Framer Motion
- Tailwind CSS

### Features
- Responsive design
- Animated UI components
- Music player
- User authentication
- Playlist management

## ConnectVerse 🌐

ConnectVerse is a social media platform built with Node.js and Express.js.

### Setup Instructions

1. Navigate to the ConnectVerse directory:
```bash
cd connectverse
```

2. Install dependencies:
```bash
npm install
```

3. Start the server:
```bash
node index.js
```

4. The server will start at:
```
http://localhost:5000
```

### Tech Stack
- Node.js
- Express.js
- MongoDB


### Features

- User profiles


## Environment Requirements

- Node.js 16.x or higher
- npm 8.x or higher
- Modern web browser
